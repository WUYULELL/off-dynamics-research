## 第二部分：按回报筛选源数据（新假设 H_Q，筛查）

- 来源：V18b 中 walker 上混合无效；V20 发现 walker 上源轨迹的归一化平均回报比目标轨迹低 15–19 分，而 hopper 上高约 4 分。H_Q 是看到这两次结果后提出的。
- 任务：walker2d-kinematic-thighjnt-medium、walker2d-kinematic-thighjnt-hard。组：T、BC、MIXALL、MIXALLQ、BCMIX、BCMIXQ。种子 2201–2205。
- 筛选：源轨迹段按终止、超时和不连续处切分，用源数据中记录的回报按 ODRL 参考回报归一化；阈值为同一任务目标轨迹段的平均归一化回报；保留不低于阈值的轨迹段，再按 V18b 去掉超时行。只用离线数据。
- 判定：MIXALLQ 或 BCMIXQ 在某任务上有效（同上标准）即在该任务上支持 H_Q；这是 5 个种子的筛查，支持后仍需新种子确认。筛选组与未筛选组的比较为描述性。
- 局限：源轨迹回报是在源环境记录的；walker hard 上只有约 54% 的源轨迹能在目标环境复现。
