# V20 说明：两项低成本检验

授权：2026-11-17，用户选择方案 C。

## 第一部分：源数据与目标数据的质量对比（CPU，描述性）

- 任务：hopper-kinematic-legjnt-medium、walker2d-kinematic-thighjnt-medium、walker2d-kinematic-thighjnt-hard。
- 按终止、超时和不连续处切分轨迹段，统计每段回报（按 ODRL 参考回报归一化）、长度、每步奖励，以及满 1000 步的段的平均回报。
- 源轨迹的回报是在源环境中记录的。walker hard 上只有约 54% 源轨迹可在目标环境复现，对比较弱。
- 事先写下的预期：若源数据质量能解释 V18b，hopper 上源轨迹归一化平均回报应高于目标轨迹，walker medium 上应低于目标轨迹。只报告是否相符，不作为因果证明。

## 第二部分：预训练-微调动力学模型的确认（GPU）

- 来源：V19 中 FT 优于 T 只是描述性观察，假设 H_FT 是看到该结果后提出的，因此用新种子 2001–2005 检验，不复用 V19 的任何结果。
- 划分：整条轨迹留出。轨迹段按种子打乱后整段分配：测试集直到至少 20% 的行，验证集直到至少 10%，其余为训练集。训练比例 0.5、1.0（嵌套）。
- 模型：S（源模型直接用）、T（只用目标数据）、FT（源模型权重和标准化，在目标数据上微调）。网络、源模型训练、提前停止与 V19 相同。
- 主指标：训练比例 1.0 的一步状态误差。判定：hopper-morph 和 walker2d-morph 上都满足均值（T − FT）> 0 且 > 2 倍配对标准误 → 确认；否则不确认。关节限位任务只作参照。
- 模型误差更低是策略更好的必要条件，不是充分条件。规则看到结果后不修改。

## 失败处理

被信号中断的进程从头重跑，同一种子，新目录，最多 3 次。代码错误、NaN、核对失败即停止并报告，不按结果决定重跑。

## 不做的事

不训练策略，不运行仿真器，不修改迁移项目和任何已有目录，不启动下一项实验。
