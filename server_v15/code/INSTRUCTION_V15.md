# v15：源状态轨迹可跟踪性筛查（先 walker2d 形态偏移）

用户于 2026-11-12 授权。全部规则在看到任何 walker2d 结果之前写定。

## 背景

v14b 在 hopper 形态偏移上的结果：用仿真器逐步求最优跟踪动作（B2），500 条源轨迹的存活步数中位数 154 步，
能跟到 80% 长度的只有 2.2%，判定为“不可跟踪”。“保留源状态、修正动作”在该任务上不成立，原因在数据而不在学习方式。

本指令用同一测试筛查其他任务：源状态轨迹在目标仿真器里跟不跟得住。它只回答可行性，不训练、不评估策略。

## 做什么

1. **hopper-morph 回归检验**：用本包的通用跟踪程序重跑 v14b 的 B1、B2（相同的 500 条轨迹、相同的初始物理状态、相同的求解器）。
   全部 1000 条记录的存活步数须与 v14b 相同，累计回报相对差 ≤ 1e-9。不一致属于技术核验失败：停下汇报，不启动 walker2d。
2. **walker2d-morph**：
   - B0 自检：目标数据的每段轨迹都跟踪到记录末尾、终止标签逐步一致，且每步归一化残差 ≤ 8.4e-4
     （沿用 v14b 为 hopper 定下的数值，不因 walker2d 的结果调整）。不通过则不运行 B1、B2。
   - 从完整源轨迹中按固定种子 2026111501 无放回选 500 条（不足则全部使用）；起点观测含被截断速度的轨迹不参与抽样，并报告数量。
   - B1：从源轨迹初始状态出发，顺次执行源动作。
   - B2：每步从仿真器当前实际状态出发，用 v13 求解器求最接近源轨迹下一观测的有界动作并执行；仅起点使用源状态。
3. 归一化尺度：该任务目标数据当前观测逐维样本标准差（ddof=1）+ 1e-6。求解器、容差、有限差分步长、物理约定直接读取 v13 的冻结配置与代码。

## 预设解读（针对 B2，只作描述）

- **不可跟踪**：存活步数中位数 < 200，且 T/L ≥ 0.8 的轨迹不到 10%。
- **可跟踪**：T/L ≥ 0.8 的轨迹达到 50% 以上。
- **其他**：不确定。
- 判定只看存活步数。报告同时给出全部已执行步的跟踪残差分布；没摔倒但残差很大，不能当作“源状态可以复现”，此时如实说明，由我决定下一步。
- 局限：B2 是一步贪心跟踪，结论仅限这种跟踪方式。
