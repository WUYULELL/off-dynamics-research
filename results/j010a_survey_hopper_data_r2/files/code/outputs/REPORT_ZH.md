# j010a_survey_hopper_data_r2：源数据作用的全景调查（描述性，不判定）

种子 [3126, 3127, 3128]（新种子）；每个任务只跑 BC 和 BC-混合，同机同种子。主指标 Last5（最后五个评估点平均，每点 10 回合），分数按 ODRL 参考回报归一化。本实验不登记候选、不做支持/否定判定，不计入自动循环的“无进展”计数。

## 预设规则（提交前写进 research/PLAN.md）

- type：descriptive survey; no candidate, no verdict, not counted by the loop
- metric：Last5 = mean of the last five evaluation points, 10 episodes each (V21/j004-j009 metric)
- tasks：per robot: gravity 0.5 / 2.0, friction 0.5 / 2.0, kinematic (the joint not used in the screening tasks) medium / hard, morph (one part) medium / hard; target data = the ODRL medium-quality file of each task; a task whose target file is missing from the archive is dropped and reported, never replaced
- reported：per task: BC and BC-mix Last5 mean / SD, BC-mix minus BC paired by seed (mean, SE, positive seeds), fraction of evaluation episodes under 200 steps, near-set share of the source data (j005/j007 tau rule)
- note：Rules are fixed before results. 3 seeds per task: differences are descriptive and only used to choose tasks and hypotheses for later registered screens.
